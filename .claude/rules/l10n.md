# Localization

- The template is `lib/l10n/intl_fr.arb` (French). Add every key to `intl_fr.arb` **and**
  `intl_en.arb` in the same change, then run `flutter gen-l10n`. The `app_localizations*.dart`
  files are generated and committed: never edit them by hand.
- Keys are lowerCamelCase, named by meaning, prefixed by family when one exists (`error…`,
  `notification…`, `book…`). Reuse an existing key before adding one; delete keys that become
  unused.
- Placeholders are declared with their type in the `@key` metadata
  (`"age": { "type": "int" }`). Counts use ICU plurals:
  `"{days, plural, =0{Aujourd'hui} =1{Demain} other{Dans {days} jours}}"`. Never concatenate
  translated fragments.
- Dates come from `DateFormat` with the locale; the month-name keys (`january`…) are legacy.
- French voice: « vous »; warm, brief, concrete. Lead with the person and the time (« Léa fête ses
  30 ans demain »). Buttons are verbs (« Ajouter », never « OK »). Errors say what happened and
  what to do, without blame or jargon.
- French typography: lowercase months and weekdays (« 9 octobre »), narrow no-break space
  (U+202F) before `? ! : ;`, « guillemets ». One emoji at most, for celebration only.
- English mirrors the meaning, not the words.
- Code reads strings with `context.l10n.<key>`. Providers and repositories never receive
  `AppLocalizations`; the one exception is the notification texts, which `app/` injects into
  `NotificationService.configure`.
